# Foody World - Python Console Food Ordering System
Welcome to Foody World, a simple yet interactive Python-based console application for food ordering. This project showcases basic Object-Oriented Programming (OOP), input handling, and console styling using Python libraries like colorama.

# Features
1. View and choose from a list of 20 Indian restaurants with ratings.
2. Order food from a diverse menu of Indian dishes.
3. Delivery handled by a pool of 30+ delivery boys, assigned based on shortest distance.
4. Location-based filtering: Restaurants within an 8-unit radius are shown.
5. Priority and Non-priority pricing with dynamic delivery charges.
6. User inputs name, phone, location, and payment type (COD or UPI).
7. Auto-generated order bill with delivery partner assignment.
8. Easy return to the main menu.

# Concepts Used
Object-Oriented Programming (classes for Restaurant, Dish, DeliveryBoy, etc.)
Distance Calculation for filtering and delivery assignment.
Error Handling for invalid inputs.

Formatted Terminal Output using colorama 

# Requirements
Install required packages using pip: pip install colorama termcolor
# How to Run
Simply run the Python file in your terminal:
python your_script_name.py

# Payment Modes
1. Cash on Delivery (COD)
2. UPI

# Sample Flow
1. User selects Order Food
2. Enters name, coordinates, phone number
3. Chooses restaurant and dish
4. Selects priority and payment
5. Receives a detailed bill and confirmation
